# 티키피디아(Teakipedia) — 차 백과 · 스토어

《찻잎의 시간, 오늘의 한 잔》과 《최초의 가향 홍차 — 얼그레이의 모든 것》에 실린
산화도·제다·향미·페어링·우림 수치를 바탕으로, 10개 계열 **162종**을 실제 찻잎 사진과 원산지 국가와 함께 담은 PWA입니다.
10문항 「나에게 맞는 차 찾기」, 잎차·티백 우림 타이머, **쿠팡으로 이어지는 스토어**, **스마트렌즈(티백 사진·바코드)**, **파트너 회원제(개인 ⊂ 찻집 ⊂ 제조사)**, 커뮤니티, 시음 노트를 한 앱에 담았습니다.
한국어 · English · 简体中文 · 繁體中文 · **日本語** · **粵語(광동어)** 여섯 언어를 지원하고, 900px 이상에서는 PC·태블릿용 넓은 레이아웃으로 바뀝니다.

## 2026-11 전면 개편에서 달라진 것

- 아이콘·헤더 배지를 **단정한 고딕 茶**(Noto Sans KR 500 외곽선, `src_brand/v2/orthodox.py`)로 통일
- **차 백과가 1번 탭이자 기본 화면** (오늘의 차 화면은 없앴습니다)
- 차 백과 **162종** — 신규 65종 + 원산지 국가 + `images/teas/` 실물 사진 162장(CC BY-SA 등 저작자·라이선스 표기)
- 계열 버튼 순서: 전체 → 녹차·우롱차·홍차·흑차(보이차)·백차·황차 → 화차·대용차·허브차·과일차, **가로 스크롤 없이 줄바꿈**
- **스토어**: 쿠팡파트너스 숏링크 12종 + 티백 33종 + 밀크티·홍차 완제품 8종(검색 링크). 대가성 문구 포함
- **스마트렌즈**: 촬영/이미지 첨부 + `BarcodeDetector`(지원 시) + 제품명 매칭, 없는 제품 등록 폼(Supabase `community_posts`)
- **파트너 회원제 3단계**(Google Play 인앱 정기구독): 개인 3,900 / 찻집 13,900 / 제조사 23,900 — 위 등급은 아래 등급 기능 포함
- 서울 주요 찻집 14곳 무료 데이터(`data/cafes.json`) 삭제 — 파트너만 남습니다
- 여백 찻잎 SVG 일러스트(`pointer-events: none`), 6개 국기 SVG 언어 버튼(한·영·간·번·일·광동), 390px 헤더 폭 보정
- PC·태블릿(≥900px) 상단 내비게이션 + 최대 1180px 컨테이너 + 2~3열 카드 그리드

## 바로 열기

- **웹에서 바로 쓰기 (설치 없이)**: <https://choitea.github.io/teakipedia/>
  - 폰 브라우저에서 주소를 열고 메뉴 → **홈 화면에 추가**를 누르면 주소창 없는 앱으로 설치됩니다.
  - 개인정보처리방침: <https://choitea.github.io/teakipedia/privacy.html>
- **단일 파일**: `tea_fai_app_standalone.html`을 브라우저로 열면 끝 (인터넷 없이도 동작).
- **앱처럼 설치**: 아래처럼 로컬 서버를 띄운 뒤 `http://<PC IP>:8000/index.html`을 폰 크롬에서 연다.
  주소창 메뉴 → **홈 화면에 추가**를 누르면 주소창 없는 앱으로 실행되고 오프라인에서도 열립니다.
- **APK 바로 설치**: <https://choitea.github.io/teakipedia/teakipedia-release.apk> (안드로이드, 1.2.3 · 1.8MB)
  폰 브라우저에서 내려받아 열면 "출처를 알 수 없는 앱 설치" 확인을 한 번 거쳐 설치됩니다.

  ```bash
  cd tea_fai_app
  python3 -m http.server 8000
  ```

  폰과 PC가 같은 와이파이에 있어야 합니다. 웹에 올릴 때는 폴더째 HTTPS 도메인에 두면 됩니다
  (서비스 워커는 HTTPS 또는 localhost에서만 동작).

## 파트너·추천 데이터 고치기

`data/shops.json`·`data/affiliate.json`은 앱 껍데기와 따로 갱신됩니다. JSON을 고쳐 커밋하면
서비스 워커가 stale-while-revalidate로 다음 실행부터 새 값을 쓰고, 앱을 다시 설치하거나
플레이에 새 버전을 올릴 필요가 없습니다.

- 매장 전화로 개인 휴대폰 번호를 노출하지 않습니다. 풍성한뷔페는 매장 번호 `010-5563-8272`,
  홍콩티는 네이버 플레이스 링크로 안내합니다.
- 프리미엄 스폰서 매장은 `data/shops.json`(또는 `data/cafes.json`)의 해당 항목에 `"sponsor": true`를 넣으면
  "추천 매장" 배지와 함께 목록 위쪽에 정렬됩니다. 아직 등록된 스폰서 매장은 없습니다.
- 입점 신청 화면에는 계좌번호를 넣지 않습니다. 결제는 "신청 접수 → 검수 승인 → 월정액 결제
  (계좌이체·세금계산서) 안내 → 확인 후 게시" 순서로, 승인 뒤 신청서에 적힌 연락처로 개별 안내합니다.
  금액·혜택은 `data/onboarding_plans.json`에서 고칩니다.
- `affiliate.json`의 `items`에 쿠팡파트너스 숏링크를 넣고 `is_active: true`로 바꾸면 대가성
  문구와 함께 노출되고, 그 전에는 `browse`의 검색 링크(수수료 없음)만 보입니다.
- 가격은 발급·확인 시점 값이므로 화면에 "판매처 기준가"로 표기합니다.

## 검증한 것

- 390×844 모바일 뷰포트에서 4개 탭 모두 렌더링, 가로 넘침 없음, 콘솔 에러 없음
- 폰트: 언어 전환 시 `<html lang>`이 `ko`·`en`·`zh-CN`·`zh-TW`로 바뀌고, Pretendard 동적 서브셋(비동기 로드, `font-display: swap`)과 시스템 CJK 폴백을 씀. 타이머 숫자는 `tabular-nums`
- 파트너 티룸: 홈 카드에서 영업 상태(서울 시간 기준)·대표 메뉴 가격·지도/전화/플레이스, 상세에서 요일별 영업시간·메뉴·지도 3종. 취향 테스트 결과와 백과 카드에서 "이 차를 내는 찻집"·"추천 찻잎·다구"·전자책·유튜브로 연결
- 타이머: 프리셋별 기본 시간, 1·2·3포 전환, ±10초, 시작/일시정지/초기화, 완료 알림
- 차 백과: 키워드 검색, 차류 필터(6대 다류·블렌딩·대용차·허브·과일), 카드 펼침, "이 차로 타이머 맞추기"
- 취향 테스트: 10문항 진행 표시(3 / 10), 4개 언어, Best 1 + 대안 2종 추천, 결과에서 타이머·백과 연결, 다시 테스트
- 시음 노트: 저장 → 새로고침 후 유지 → 삭제
- 서비스 워커 등록 및 오프라인 재접속, 단일 파일 실행
- 티백: 33종 렌더, 브랜드·차종·향미·카페인 필터, 검색(이름·브랜드·향), 카드 펼침, "타이머로 우리기"로 제품 온도·시간이 타이머에 반영, 잎차 탭 복귀
- 찻집: 파트너 2곳 상단 강조 + 디렉터리 14곳, 지역·취향 태그·검색 필터, 상세(요일별 영업시간·주소·지도 3종), 입점 신청 바
- 커뮤니티: 샘플 글 5개 + 글 작성(종류·별점·차/티백·닉네임·본문), 필터, 좋아요/도움돼요, 삭제, 새로고침 후 유지
- 입점 신청: 플랜 2종(월 19,000·39,000원) 선택, 필수값 검증, 로컬 저장 + 요약 복사 + `rotroka@naver.com` 메일 링크, 신청 내역 표시
- 4개 언어(한/영/중간/중번) 전환 시 새 화면 문구 누락 없음, 360·390·412·430px 가로 넘침 없음, 콘솔 에러 0
